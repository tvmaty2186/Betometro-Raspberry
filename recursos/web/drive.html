LOS PASOS

  1. Crear el proyecto: console.cloud.google.com/projectcreate
  2. Activar la API de Drive: abrir → «Habilitar»
  3. Pantalla de consentimiento: abrir (nombre Betómetro, tu mail, «Externo») y después «Publicar app»
  4. Cliente: abrir → «TVs y dispositivos de entrada limitada» → bajar el JSON
  5. Subirlo acá arriba
  6. En el Betómetro: Ajustes → Google Drive → Conectar
